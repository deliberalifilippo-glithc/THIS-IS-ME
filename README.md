# THIS IS ME? — v7 Postdigital Position

Interactive web artwork for the ETH-TECH Art Contest theme **“Inhabiting Technological Present and Futures: What’s my postdigital positionality?”**

## Core idea
The project no longer asks only whether the Internet can identify a person. It asks how a temporary position emerges between public traces, declared choices, technological capabilities, the author’s own media practices and the system that connects them.

The work treats identity less as a fixed object and more as something that **happens while technological environments are inhabited**.

> I am not only what I know.  
> I am also what my relations allow me to do.

## Narrative structure
1. **BEFORE YOU / MISREPRESENTATION** — public image search, possible matches and rejected assumptions.
2. **INHABITING / NEGOTIATION** — portrait plus short questions about media practices and mediated abilities.
3. **ENTANGLEMENT** — the portrait is erased and a positional network emerges: PUBLIC, DECLARED, AUTHOR, MEDIATED CAPABILITY, SYSTEM INFERENCE, REJECTED and UNKNOWN.
4. **POSITION / REFLECTION** — no psychological score: only traces, relations, contradictions and unmapped areas.

Final statement:

> This is not you.  
> This is a position that happened here.  
> **THIS IS ALSO ME.**

## Visual language
- mobile-first vertical experience
- black background, monochrome portrait, cyan luminous nodes
- network grows while the visitor inhabits the work
- rejected traces fade but remain visible
- no central `YOU` node; the map uses `CURRENT POSITION`

## Current technical basis
The app remains a single-file prototype (`index.html`) so it can be deployed directly from GitHub to Vercel. Public image search uses Wikimedia Commons and public contextual traces use Wikipedia when available. Webcam/photo handling remains local in the browser.
